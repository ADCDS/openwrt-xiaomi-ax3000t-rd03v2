PHASE 0 - capability handshake on the installed v1.10 12.5 image (probe kmod, no flash)
  NSS_WIFILI_SEND_MESH_CAPABILITY_INFO, sent the way donor ath11k_nss_mesh_capability() sends it:
    if 203 (NSS_WIFILI_INTERNAL_INTERFACE, radio0): response ACK (0) error 0
    if 215 (NSS_WIFILI_EXTERNAL_INTERFACE0, radio1): response ACK (0) error 0
  cap_info.mesh_enable in the reply echoes the request (sent 0 -> 0, sent 1 -> 1), so it
  carries no signal. Only the response code counts, and ath11k enables mesh offload on != EMSG.

ROOT CAUSE FOUND, 27 Sep

    with no data frame reaching the host. frame_mode=1 AP mode is broken on both socs in this stack. It
    does not discriminate between radios; not pursued further.
  Confound found: every radio1 test used an OPEN mesh (the gateway's iw-only mesh), while the working
    radio0 tests used SAE (syd). Code: ath11k authorizes a peer in NSS (NSS_WIFILI_PEER_UPDATE_AUTH_FLAG)
    only in ath11k_mac_op_set_key(), and ASSOC->AUTHORIZED sends nothing to NSS for AP or mesh peers.
    A keyless peer is never authorized in NSS.
  Test A, radio0 with an OPEN mesh to syd (no gateway): 0/20, no frame reaches the host, exactly like radio1.
  Fix 999-991 (authorize mesh peers in NSS at AUTHORIZED) plus TEMP A/B switch and NSS per-peer stats

SAE RE-JOIN AFTER AN IN-PLACE RESTART: WATCHDOG RULE (27 Sep)
  rd03v2-watchdog counts ath11k "pdev N successfully recovered" per device (baselined at arm time, like
  the respawn-suppressed check). When a device's count goes up, it reloads that radio's encrypted mesh
  supplicants (netifd config mode=mesh, encryption != none) via `ubus call wpa_supplicant.<if> reload`,
  under a deadline. APs and open meshes are left alone.
  Bench test on the clean build: the watchdog's code sourced on the bench, baseline taken, hw-restart
    of c000000.wifi with the SAE mesh to syd up. recovered_devs -> [c000000.wifi]; mesh_rejoin logged
    "c000000.wifi restarted in place: joined the encrypted mesh on phy0-mesh0 again"; the next sample
    was quiet. syd re-peered, pings 0, 0, 6/10, 10/10. Without it, SAE stayed at 0 until a manual
    reload.
