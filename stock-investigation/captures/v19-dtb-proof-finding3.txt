=== Finding #3: offline DTB proof that deleting q6_mem_regions is a no-op ===

Method: compile the board DTS before and after the change against the same
staged tree (mainline v6.12 ipq5018.dtsi + the OpenWrt qualcommax patches that
touch it, notably 0189-...-bringup-q6.patch which declares q6_region), then
decompile both DTBs and diff. This tests the built artifact, not the source.

Conclusion: the ONLY change to the built device tree is the removal of the
duplicate q6_mem_regions@4b000000 node. wcss@4b000000 keeps base 0x4b000000,
size 0x3000000, no-map and its phandle, so the 48 MiB Q6 carve-out is
bit-for-bit what it was. Nothing referenced the deleted label: a repo-wide
grep for q6_mem_regions returned exactly one hit, its own declaration.
